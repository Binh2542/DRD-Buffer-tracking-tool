# the handful this project imports directly) - build_linux.sh recreates
# the venv from scratch on every build, and matplotlib/selenium/
# firebase-admin's own transitive dependency ranges drift over time (a
# clean install run today can pull noticeably different numpy/matplotlib
# versions than one run last week). That drift is the reason PyInstaller
# builds a few days apart came out wildly different sizes (42MB/68MB/31MB
# for the exact same source code) and, at least once, produced a Linux
# build that would not start at all - pinning everything makes every
# future build reproduce the exact dependency set already verified
# working, on Windows and Linux alike.
